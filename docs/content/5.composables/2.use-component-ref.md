title: useComponentRef
description: Type-safe reactive composable for reading child component state snapshots, syncing them to page/component data, and calling imperative FSM APIs.
---

## Overview

`useComponentRef` connects a parent MiniProgram Page or Component to a child Code UI component by selector (or direct instance reference). It replaces manual `selectComponent()` polling and snapshot boilerplate with:

- **Reactive snapshot syncing**: diffs and batches updates to `this.data[key]` via `setData`.
- **Synchronous reads**: access `ref.snapshot` or `ref.getSnapshot()` at any time, even when the child restricts `selectComponent()` via `exportApiKeys`.
- **Type-safe imperative API**: call child methods via `ref.api` (with convenience aliases `clear` and `reset` when `clearValue` / `resetValue` exist) or dispatch events with `ref.send(event)`.
- **Automatic lifecycle binding**: defers binding until `onReady` / `ready` if the child is not mounted yet, and auto-disposes subscriptions on `onUnload` / `detached`.

```ts
import { useComponentRef } from "@code-id-labs/composables";
```

---

## Usage

### Syncing State & Calling Imperative Methods

Pass `this`, a CSS selector (`"#otpInput"`), and an optional `key` to mirror the child component's reactive snapshot into `this.data`.

::code-group

```html [index.wxml]
<c-input
  id="userInput"
  placeholder="Enter handle..."
  clearable="{{ true }}"
/>

<c-pin-input
  id="otpInput"
  label="4-Digit Security OTP"
  length="{{ 4 }}"
/>

<view class="text-xs text-muted">
  Username: {{ user.value || "(empty)" }}
</view>
<view class="text-xs text-muted">
  OTP: {{ otp.valueAsString || "(empty)" }} ({{ otp.isValueComplete ? "complete" : "incomplete" }})
</view>

<c-button label="Clear OTP" bind:tap="handleClearOtp" />
<c-button label="Submit" bind:tap="handleSubmit" />
```

```ts [index.ts]
import { useComponentRef, type UseComponentRefReturn } from "@code-id-labs/composables";
import type { InputApi } from "@code-id-labs/input";
import type { PinInputApi } from "@code-id-labs/pin-input";

Page({
  data: {
    otp: {} as Record<string, any>,
    user: {} as Record<string, any>,
  },

  otpRef: null as UseComponentRefReturn<any, PinInputApi> | null,
  userRef: null as UseComponentRefReturn<any, InputApi> | null,

  onReady() {
    this.otpRef = useComponentRef<PinInputApi>(this, "#otpInput", {
      key: "otp",
      onChange: (snapshot) => {
        if (snapshot.isValueComplete) {
          wx.showToast({ title: "Code Complete!", icon: "success" });
        }
      },
    });

    this.userRef = useComponentRef<InputApi>(this, "#userInput", {
      key: "user",
    });
  },

  handleClearOtp() {
    this.otpRef?.api.clear?.();
  },

  handleSubmit() {
    const otpSnap = this.otpRef?.snapshot;
    const userSnap = this.userRef?.getSnapshot();
    console.log(userSnap?.value, otpSnap?.valueAsString);
  },
});
```

::

### Custom `connect` Projection

Provide a `connect(service)` function when you only want to project a subset of state or derived fields into `this.data[key]` and `onChange`.

```ts [index.ts]
const counterRef = useComponentRef(this, "#counter", {
  key: "summary",
  connect: (service) => ({
    count: service.context.get("count") ?? 0,
    isPositive: (service.context.get("count") ?? 0) > 0,
  }),
});
```

### Sending Machine Events & Cleanup

Use `ref.send(event)` to dispatch events directly to the child state machine, and `ref.stop()` if you need to dispose the subscription before `onUnload` / `detached`.

```ts [index.ts]
this.modalRef?.send({ type: "OPEN" });

// Optional manual cleanup (also runs automatically on onUnload / detached)
this.modalRef?.stop();
```

::callout{icon="i-lucide-shield-check" color="info"}
`useComponentRef` defines `toJSON()` returning `undefined` and marks `service` as non-enumerable, so assigning a ref object to `this.data` by accident will not trigger circular JSON serialization errors.
::

## API

### `useComponentRef(instance, target, options?)`

| Parameter | Type | Description |
| --- | --- | --- |
| `instance` | `UseComponentRefInstance` | Parent MiniProgram Page or Component instance (`this`). |
| `target` | `UseComponentRefTarget` | Selector string passed to `instance.selectComponent(target)` (e.g. `"#myModal"`), or a component reference object. |
| `options` | `UseComponentRefOptions<T, Data>` | Optional sync, projection, and change callback configuration. |

### `UseComponentRefOptions<T, Data>`

| Option | Type | Description |
| --- | --- | --- |
| `key` | `string` | Data key under `instance.data` where diffed snapshots are synced via `setData`. |
| `onChange` | `(snapshot: Data) => void` | Callback invoked on initial bind and whenever the component machine transitions. |
| `connect` | `(service: Service<T>) => Data` | Custom projection function returning the snapshot shape derived from the child service. |

### `UseComponentRefReturn<T, Data>`

| Property / Method | Type | Description |
| --- | --- | --- |
| `snapshot` | `Data \| undefined` | Getter returning the latest cached (or computed) snapshot synchronously. |
| `getSnapshot` | `() => Data \| undefined` | Function returning the latest cached (or computed) snapshot. |
| `api` | `UseComponentRefApi<Data>` | Proxy exposing callable child API methods (plus `clear` / `reset` aliases when `clearValue` / `resetValue` exist). |
| `send` | `(event: T["event"]) => void` | Dispatches an event directly to the child state machine. |
| `service` | `Service<T> \| undefined` | Non-enumerable getter for the underlying machine service. |
| `stop` | `() => void` | Disposes the subscription and clears any pending batched `setData` updates. |
