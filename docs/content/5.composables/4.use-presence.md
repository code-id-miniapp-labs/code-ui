title: usePresence
description: Parent-level presence composable and behavior for lazy-mounting and truly unmounting <c-drawer>, <c-modal>, <c-action-sheet>, and custom overlay components after exit animations finish.
---

## Overview

`usePresence` coordinates `{ open, present, mounted, state }` in a parent Page or Component so heavy overlays stay **unmounted** while closed, stay **mounted** while playing their exit transition, and **truly unmount** via `wx:if` as soon as `bind:exitcomplete` fires.

```ts
import { usePresence } from "@code-id-labs/composables";
```

For parent `Component(...)` definitions that prefer WeChat `Behavior` composition, Code UI also exports `createPresenceBehavior`:

```ts
import { createPresenceBehavior } from "@code-id-labs/components/behaviors/presence";
```

::callout{icon="i-lucide-info"}
**Why use `usePresence` instead of only toggling `open`?**
In WeChat MiniProgram, `<slot>` children inside a closed `<c-drawer>` or `<c-modal>` — or inside a custom component extending them — remain attached to the parent page tree even when the overlay hides itself internally. Pairing `wx:if="{{overlay.mounted}}"` in the parent template with `usePresence()` and `bind:exitcomplete` ensures closed overlays consume **zero** component instances and listeners while keeping exit animations intact.
::

## Usage

### With `<c-drawer>`, `<c-modal>`, and `<c-action-sheet>`

Bind `wx:if="{{filterDrawer.mounted}}"`, `open="{{filterDrawer.open}}"`, `bind:close`, and `bind:exitcomplete`:

::code-group

```html [index.wxml]
<c-button label="Open Drawer" bind:tap="openDrawer" />

<c-drawer
  wx:if="{{ filterDrawer.mounted }}"
  open="{{ filterDrawer.open }}"
  bind:close="closeDrawer"
  bind:exitcomplete="onDrawerExitComplete"
>
  <view slot="header" class="text-base font-semibold">Filters</view>
  <view class="py-2">Content is mounted lazily and detached after exit.</view>
</c-drawer>
```

```ts [index.ts]
import { usePresence, type UsePresenceReturn } from "@code-id-labs/composables";

Page({
  data: {
    filterDrawer: {
      open: false,
      present: false,
      mounted: false,
      state: "unmounted",
    },
  },

  drawer: null as UsePresenceReturn | null,

  onLoad() {
    this.drawer = usePresence({
      target: this,
      key: "filterDrawer",
    });
  },

  onUnload() {
    this.drawer?.stop();
  },

  openDrawer() {
    this.drawer?.show();
  },

  closeDrawer() {
    this.drawer?.hide();
  },

  onDrawerExitComplete() {
    this.drawer?.onExitComplete();
  },
});
```

### With Custom Components Extending `<c-drawer>` or `<c-modal>`

When you wrap `<c-drawer>` or `<c-modal>` inside a domain-specific custom component (for example `<payment-drawer>` or `<confirm-modal>`):

1. Forward `bind:close` and `bind:exitcomplete` from the inner Code UI overlay via `this.triggerEvent(...)`.
2. Render your custom component behind `wx:if="{{paymentDrawer.mounted}}"` in the parent page.

::code-group

```html [components/confirm-modal/index.wxml]
<c-modal
  open="{{ open }}"
  title="{{ title }}"
  bind:close="handleClose"
  bind:exitcomplete="handleExitComplete"
>
  <view>Are you sure you want to delete this item?</view>
  <view slot="footer" class="flex justify-end gap-2">
    <c-button size="sm" variant="ghost" label="Cancel" bind:tap="handleClose" />
    <c-button size="sm" color="danger" label="Delete" bind:tap="handleConfirm" />
  </view>
</c-modal>
```

```ts [components/confirm-modal/index.ts]
Component({
  options: {
    styleIsolation: "shared",
  },
  properties: {
    open: { type: Boolean, value: false },
    title: { type: String, value: "Confirm" },
  },
  methods: {
    handleClose() {
      this.triggerEvent("close");
    },
    handleExitComplete() {
      this.triggerEvent("exitcomplete");
    },
    handleConfirm() {
      this.triggerEvent("confirm");
      this.triggerEvent("close");
    },
  },
});
```

```html [pages/detail/index.wxml]
<c-button color="danger" label="Delete Item" bind:tap="openConfirm" />

<confirm-modal
  wx:if="{{ confirmModal.mounted }}"
  open="{{ confirmModal.open }}"
  title="Delete Order?"
  bind:close="closeConfirm"
  bind:exitcomplete="onConfirmExitComplete"
  bind:confirm="handleDelete"
/>
```

```ts [pages/detail/index.ts]
import { usePresence, type UsePresenceReturn } from "@code-id-labs/composables";

Page({
  data: {
    confirmModal: {
      open: false,
      present: false,
      mounted: false,
      state: "unmounted",
    },
  },

  confirmCtrl: null as UsePresenceReturn | null,

  onLoad() {
    this.confirmCtrl = usePresence({
      target: this,
      key: "confirmModal",
    });
  },

  onUnload() {
    this.confirmCtrl?.stop();
  },

  openConfirm() {
    this.confirmCtrl?.show();
  },

  closeConfirm() {
    this.confirmCtrl?.hide();
  },

  onConfirmExitComplete() {
    this.confirmCtrl?.onExitComplete();
  },

  handleDelete() {
    console.log("Deleted");
  },
});
```

### Managing Multiple Drawers / Modals on One Page (`key: [...]`)

When a single page or component hosts multiple overlays (for example, `filter`, `sort`, and `payment` drawers), pass an array of names to `key` in `usePresence` or `createPresenceBehavior` instead of creating separate controllers one by one.

Each overlay is synced granularly at `this.data[name]` (via `setData({ [name]: snapshot })`), and `show`, `hide`, `toggle`, and `onExitComplete` accept **either** an overlay name (`"filter"`) **or** a MiniProgram event carrying `data-name` / `data-presence`:

::code-group

```html [index.wxml]
<view class="flex gap-2">
  <c-button data-name="filter" label="Filter" bind:tap="openOverlay" />
  <c-button data-name="sort" label="Sort" bind:tap="openOverlay" />
  <c-button data-name="payment" label="Payment" bind:tap="openOverlay" />
</view>

<filter-drawer
  wx:if="{{ filter.mounted }}"
  open="{{ filter.open }}"
  data-name="filter"
  bind:close="closeOverlay"
  bind:exitcomplete="onOverlayExitComplete"
/>

<sort-drawer
  wx:if="{{ sort.mounted }}"
  open="{{ sort.open }}"
  data-name="sort"
  bind:close="closeOverlay"
  bind:exitcomplete="onOverlayExitComplete"
/>

<payment-drawer
  wx:if="{{ payment.mounted }}"
  open="{{ payment.open }}"
  data-name="payment"
  bind:close="closeOverlay"
  bind:exitcomplete="onOverlayExitComplete"
/>
```

```ts [index.ts]
import {
  usePresence,
  type UsePresenceMultiReturn,
} from "@code-id-labs/composables";

const OVERLAYS = ["filter", "sort", "payment"] as const;
type OverlayName = (typeof OVERLAYS)[number];

Page({
  data: {} as Record<string, any>,

  overlaysCtrl: null as UsePresenceMultiReturn<OverlayName> | null,

  onLoad() {
    this.overlaysCtrl = usePresence({
      target: this,
      key: OVERLAYS,
    });
  },

  onUnload() {
    this.overlaysCtrl?.stop();
  },

  openOverlay(e: WechatMiniprogram.BaseEvent) {
    this.overlaysCtrl?.show(e);
  },

  closeOverlay(e: WechatMiniprogram.BaseEvent) {
    this.overlaysCtrl?.hide(e);
  },

  onOverlayExitComplete(e: WechatMiniprogram.BaseEvent) {
    this.overlaysCtrl?.onExitComplete(e);
  },
});
```

```ts [Component with createPresenceBehavior]
import { createPresenceBehavior } from "@code-id-labs/components/behaviors/presence";

Component({
  behaviors: [
    createPresenceBehavior({
      key: ["filter", "sort", "payment"],
    }),
  ],
  // Automatically exposes:
  // openPresence(e), closePresence(e), togglePresence(e),
  // handlePresenceExitComplete(e), closeAllPresence()
});
```

### Keep-Alive After First Mount (`unmountOnExit: false`)

Set `lazyMount: true` and `unmountOnExit: false` to defer initial mounting until the user opens the overlay once, then preserve its internal form state across subsequent opens:

```ts
this.drawer = usePresence({
  target: this,
  key: "filterDrawer",
  lazyMount: true,
  unmountOnExit: false,
});
```

### Safety Fallback Timeout (`duration`)

When driving a custom component that might not always emit `exitcomplete`, pass a fallback `duration` (in milliseconds). If `onExitComplete()` arrives earlier, the timer is cancelled immediately; if the user reopens mid-exit, the timer is cancelled and stale exit events are ignored.

```ts
this.drawer = usePresence({
  target: this,
  key: "filterDrawer",
  duration: 350,
});
```

### Component Behavior Composition (`createPresenceBehavior`)

Inside a parent `Component(...)`, you can mix in `createPresenceBehavior` directly with zero lifecycle boilerplate:

```ts
import { createPresenceBehavior } from "@code-id-labs/components/behaviors/presence";

Component({
  behaviors: [
    createPresenceBehavior({
      key: "filterDrawer",
      lazyMount: true,
      unmountOnExit: true,
    }),
  ],
});
```

For `key: "filterDrawer"`, the behavior initializes `this.data.filterDrawer` and generates:
- `openFilterDrawer()` / `showFilterDrawer()`
- `closeFilterDrawer()` / `hideFilterDrawer()`
- `toggleFilterDrawer()`
- `setFilterDrawerOpen(next: boolean)`
- `handleFilterDrawerExitComplete()`

For an array `key: ["filter", "sort", "payment"]`, the behavior initializes `this.data.filter`, `this.data.sort`, and `this.data.payment`, and generates shared methods that accept either a name or a WXML event (`data-name` / `data-presence`):
- `openPresence(nameOrEvent)` / `showPresence(nameOrEvent)`
- `closePresence(nameOrEvent)` / `hidePresence(nameOrEvent)`
- `togglePresence(nameOrEvent)`
- `setPresenceOpen(name, next)`
- `handlePresenceExitComplete(nameOrEvent)`
- `closeAllPresence()` / `hideAllPresence()`

## API

### `usePresence(options?)`

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `target` | `{ setData?: (data: Record<string, unknown>) => void }` | `undefined` | Optional Page or Component instance (`this`) to sync presence snapshots via `setData`. |
| `key` | `string \| readonly K[]` | `undefined` | Single data key under `target.data` (e.g. `key: "filterDrawer"`), or an array of keys (e.g. `key: ["filter", "sort"] as const`) to manage multiple overlays granularly at `target.data[name]`. When omitted with `target`, syncs `{ open, present, mounted, presenceState }` at the root of `target.data`. |
| `initialPresent` | `boolean \| Partial<Record<K, boolean>>` | `false` | Initial open/present state (boolean in single mode, or per-key map in multi-key mode). |
| `lazyMount` | `boolean` | `true` | Defer mounting until `show()` is called for the first time. |
| `unmountOnExit` | `boolean` | `true` | Set `mounted: false` once exit completes. |
| `duration` | `number \| null` | `null` | Optional auto-exit timeout in ms (`0` for immediate unmount; `null` waits for `onExitComplete()`). |
| `onChange` | `(snapshot: PresenceSnapshot) => void` or `(name: K, snapshot: PresenceSnapshot) => void` | `undefined` | Called whenever `{ present, open, mounted, state }` changes. |
| `onExitComplete` | `() => void` or `(name: K) => void` | `undefined` | Called once the exit animation settles into `"unmounted"`. |

### `UsePresenceReturn` (single `key`)

| Property / Method | Type | Description |
| --- | --- | --- |
| `present` | `boolean` | Whether the overlay is currently present (`state === "open"`). |
| `open` | `boolean` | Alias for `present` — binds directly to `open="{{...}}"`. |
| `mounted` | `boolean` | Whether the overlay should stay mounted — binds directly to `wx:if="{{...}}"`. |
| `state` | `"unmounted" \| "open" \| "exiting"` | Current presence lifecycle state. |
| `getState` | `() => PresenceSnapshot` | Returns `{ present, open, mounted, state }`. |
| `show` | `() => void` | Mounts (if unmounted) and opens; cancels any in-flight exit animation. |
| `hide` | `() => void` | Transitions `open` → `exiting` while keeping `mounted: true` until exit completes. |
| `setPresent` | `(next: boolean) => void` | Imperatively calls `show()` or `hide()`. |
| `toggle` | `() => void` | Toggles between `show()` and `hide()`. |
| `onExitComplete` | `() => void` | Bind to `bind:exitcomplete` to settle `"exiting"` → `"unmounted"`. Ignored if already reopened. |
| `stop` | `() => void` | Clears any pending exit timer (call in `onUnload` / `detached`). |

### `UsePresenceMultiReturn<K>` (array `key`)

| Method | Type | Description |
| --- | --- | --- |
| `getState` | `(name: K) => PresenceSnapshot` | Returns the current snapshot for `name`. |
| `getAllStates` | `() => Record<K, PresenceSnapshot>` | Returns all managed snapshots keyed by name. |
| `show` | `(nameOrEvent: K \| PresenceEventLike) => void` | Opens by name or WXML event (`data-name` / `data-presence`). |
| `hide` | `(nameOrEvent: K \| PresenceEventLike) => void` | Starts exit by name or WXML event (`data-name` / `data-presence`). |
| `setPresent` | `(name: K, next: boolean) => void` | Imperatively calls `show(name)` or `hide(name)`. |
| `toggle` | `(nameOrEvent: K \| PresenceEventLike) => void` | Toggles by name or WXML event. |
| `onExitComplete` | `(nameOrEvent: K \| PresenceEventLike) => void` | Bind to `bind:exitcomplete` with `data-name` / `data-presence` to settle `"exiting"` → `"unmounted"`. |
| `hideAll` | `() => void` | Hides all currently open overlays. |
| `stop` | `() => void` | Clears all pending exit timers (call in `onUnload` / `detached`). |
