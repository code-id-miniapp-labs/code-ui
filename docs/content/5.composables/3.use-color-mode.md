description: Opt-in composable for reading, subscribing to, and toggling runtime color mode ("light", "dark", "system") in MiniProgram pages and components.
---

## Overview

`useColorMode` provides a reactive API for reading and switching the active color mode (`"light"`, `"dark"`, or `"system"`).

Calling `setMode()` or `toggle()` updates the shared theme registry directly, which automatically updates `<c-app>` (including `data-theme`, dark mode styling, and `themeCssVars`) as well as `<c-popover>` and `<c-select>` when rendered inside `<root-portal>`.

```ts
import { useColorMode } from "@code-id-labs/composables";
```

::callout{icon="i-lucide-info"}
When using `@code-id-labs/plugin-vite`, `<c-app>` is automatically injected into your pages, so `useColorMode()` works out of the box without manual wrapper setup. Note that an explicit `theme="light"` or `theme="dark"` prop on `<c-app>` takes precedence over `useColorMode()`.
::

## Usage

### Basic & Module-Level Usage

Initialize `useColorMode()` once at module top-level (outside `Page()` / `Component()`), or inside a lifecycle method when you want to bind `target` and `key` for automatic `setData` syncing.

::code-group

```html [index.wxml]
<view class="p-4 flex items-center gap-2">
  <c-button label="Light" size="xs" bind:tap="setLight" />
  <c-button label="Dark" size="xs" bind:tap="setDark" />
  <c-button label="System" size="xs" variant="outline" bind:tap="setSystem" />
  <c-button label="Toggle" size="xs" variant="soft" bind:tap="toggleMode" />
</view>
```

```ts [index.ts]
import { useColorMode } from "@code-id-labs/composables";

const colorMode = useColorMode();

Page({
  setLight() {
    colorMode.setMode("light");
  },

  setDark() {
    colorMode.setMode("dark");
  },

  setSystem() {
    colorMode.setMode("system");
  },

  toggleMode() {
    colorMode.toggle();
  },
});
```

::

### Syncing to `this.data` & Listening for Changes

Pass `target: this` and `key` to mirror `AppThemeState` (`{ colorMode, resolvedMode, colors, cssVars }`) into `this.data[key]`, or pass `onChange` to react to updates.

```ts [index.ts]
import { useColorMode, type UseColorModeReturn } from "@code-id-labs/composables";

Page({
  data: {
    theme: {} as Record<string, any>,
  },

  colorModeRef: null as UseColorModeReturn | null,

  onLoad() {
    this.colorModeRef = useColorMode({
      target: this,
      key: "theme",
      onChange: (state) => {
        console.log("Resolved mode:", state.resolvedMode);
      },
    });
  },

  onUnload() {
    this.colorModeRef?.stop();
  },
});
```

## API

### `useColorMode(options?)`

| Option | Type | Description |
| --- | --- | --- |
| `target` | `any` | Optional Page or Component instance (`this`) to sync state into `target.data`. |
| `key` | `string` | Data key under `target.data` (e.g. `key: "theme"`). |
| `initialValue` | `"light" \| "dark" \| "system"` | Initial color mode to apply immediately if provided. |
| `onChange` | `(state: AppThemeState) => void` | Callback invoked on initial bind and whenever theme mode or colors change. |

### `UseColorModeReturn`

| Property / Method | Type | Description |
| --- | --- | --- |
| `mode` | `"light" \| "dark" \| "system"` | Current configured color mode. |
| `resolvedMode` | `"light" \| "dark"` | Effective resolved mode (`"system"` resolves via `wx.onThemeChange`). |
| `colors` | `AppThemeColors` | Active runtime color overrides. |
| `cssVars` | `string` | Compiled CSS variable string. |
| `getState` | `() => AppThemeState` | Returns the full current `AppThemeState` snapshot. |
| `setMode` | `(mode: AppColorMode) => void` | Sets the active color mode and notifies all subscribers. |
| `toggle` | `() => void` | Toggles between `"light"` and `"dark"`. |
| `stop` | `() => void` | Disposes the active subscription. |
