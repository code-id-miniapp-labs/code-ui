## Overview

`useToast` lets you trigger and manage transient toast notifications from page and component scripts without manually toggling `<c-toast>` visibility in WXML. It works with the `<c-app>` toast host (or falls back to the current page from `getCurrentPages()` when `target` is omitted).

```ts
import { useToast } from "@code-ui/composables";
```

::callout{icon="i-lucide-info"}
When using `@code-ui/plugin-vite`, `<c-app>` is automatically injected into your pages as the toast host, so you can call `useToast(this)` in any page without manually wrapping templates in `<c-app>`.
::

---

## Usage

### Basic & Shorthand Methods

Initialize `useToast()` once at the top level of your module (outside `Page()` or `Component()`), or inside a method when you want to pin a specific `target`. Call `add()`, `show()`, or semantic shorthand helpers (`success`, `error`, `warning`, `info`, `loading`).

::code-group

```html [index.wxml]
<view class="p-4 flex flex-col gap-3">
  <c-button label="Save Profile" bind:tap="onSave" />
  <c-button label="Sync Data" variant="outline" bind:tap="onSync" />
</view>
```

```ts [index.ts]
import { useToast } from "@code-ui/composables";

const toast = useToast();

Page({
  onSave() {
    toast.success("Profile saved", {
      description: "Your account changes are now live.",
    });
  },

  onSync() {
    // loading() defaults to duration: 0 and an animated spinner icon
    const id = toast.loading("Syncing data...");

    setTimeout(() => {
      toast.update(id, {
        color: "success",
        title: "Sync complete",
        duration: 3000,
      });
    }, 1500);
  },
});
```

::

### Updating, Dismissing & Clearing

`add()`, `show()`, and all shorthand helpers return the generated toast `id` (`string`). Use that `id` to patch, dismiss, or remove a toast, or clear all active toasts at once.

```ts [index.ts]
const id = toast.add({
  title: "Uploading file...",
  description: "report.pdf",
  duration: 0,
  actions: [
    {
      label: "Cancel",
      variant: "ghost",
      onClick: () => toast.dismiss(id),
    },
  ],
});

// Update an existing toast in place
toast.update(id, {
  title: "Upload complete",
  color: "success",
  duration: 3000,
});

// Dismiss with transition, remove immediately, or clear all
toast.dismiss(id);
toast.remove(id);
toast.clear();
```

### Configuring Max Visible Toasts

Pass `{ max }` or `{ target, max }` to `useToast(...)`, or call `toast.config({ max })` to limit how many toasts stack simultaneously.

```ts [index.ts]
const toast = useToast({ max: 3 });

// Or update later:
toast.config({ max: 5 });
```

## API

### `useToast(optionsOrTarget?)`

| Parameter | Type | Description |
| --- | --- | --- |
| `optionsOrTarget` | `UseToastOptions \| any` | Optional MiniProgram Page/Component instance (`this`), or `{ target?: any; max?: number }`. Defaults to the active page from `getCurrentPages()`. |

### `UseToastReturn`

| Method | Signature | Description |
| --- | --- | --- |
| `add` | `(toast: ToastOptions) => string` | Adds a toast to the host queue and returns its `id`. |
| `show` | `(toast: ToastOptions) => string` | Alias for `add`. |
| `update` | `(id: string, patch: Partial<Omit<ToastOptions, "id">>) => void` | Updates an active toast by `id`. |
| `dismiss` | `(id: string) => void` | Closes a toast with its exit transition. |
| `remove` | `(id: string) => void` | Removes a toast from the host immediately. |
| `clear` | `() => void` | Clears all toasts on the target host. |
| `config` | `(options: { max?: number }) => void` | Updates toast host configuration (such as `max` stack size). |
| `success` | `(titleOrOptions, options?) => string` | Adds a `"success"` colored toast. |
| `error` | `(titleOrOptions, options?) => string` | Adds a `"danger"` colored toast. |
| `warning` | `(titleOrOptions, options?) => string` | Adds a `"warning"` colored toast. |
| `info` | `(titleOrOptions, options?) => string` | Adds an `"info"` colored toast. |
| `loading` | `(titleOrOptions, options?) => string` | Adds a `"loading"` toast (`duration: 0` and spinning icon by default). |

### `ToastOptions`

| Property | Type | Description |
| --- | --- | --- |
| `id` | `string` | Custom toast identifier (auto-generated when omitted). |
| `title` | `string` | Primary toast heading text. |
| `description` | `string` | Secondary supporting message. |
| `icon` | `string` | Leading icon name passed to `<c-icon>`. |
| `mode` | `"default" \| "native"` | Visual layout mode (`"default"` card or `"native"` compact overlay). |
| `color` | `string` | Semantic color token (`"primary"`, `"secondary"`, `"success"`, `"info"`, `"warning"`, `"error"`, `"danger"`, `"neutral"`, `"loading"`). |
| `variant` | `string` | Surface variant in `"default"` mode (`"outline"`, `"solid"`, `"soft"`, `"subtle"`). |
| `orientation` | `"horizontal" \| "vertical"` | Content/action orientation (`"horizontal"` also enables pill layout in `"native"` mode). |
| `placement` | `"top" \| "center" \| "bottom"` | Screen anchor position. |
| `duration` | `number` | Auto-dismiss duration in milliseconds (`0` disables auto-dismiss). |
| `progress` | `boolean \| { color?: string }` | Enables or styles the auto-dismiss progress bar. |
| `progressPosition` | `"top" \| "bottom"` | Position of the progress bar within the toast card. |
| `close` | `boolean \| ToastCloseProps` | Shows or customizes the close trigger button. |
| `actions` | `ToastAction[]` | Action buttons rendered inside `"default"` mode toasts. |
| `ui` | `ToastUI` | Per-slot class overrides. |
| `className` | `string` | Additional CSS classes merged onto the root slot. |
| `onAction` | `(details: { action: ToastAction; index: number }) => void` | Callback invoked when an action button is tapped. |
| `onDismiss` | `() => void` | Callback invoked when the toast is dismissed. |
