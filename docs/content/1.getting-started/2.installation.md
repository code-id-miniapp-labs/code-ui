Code UI runs directly on **native WeChat MiniProgram (`WXML`, `WXSS`, and TypeScript)** with no Vue or React runtime required. It is powered by **[weapp-vite](https://vite.weapp.dev/)** and **Tailwind CSS v4** (`weapp-tailwindcss`) for Vite bundling, npm support, and compile-time styling.

You can scaffold a pre-configured project in seconds with `@code-ui/cli` or add Code UI to an existing `weapp-vite` project.

## Quick Start (New Project)

Use `@code-ui/cli` to generate a ready-to-run WeChat MiniProgram starter project with `weapp-vite`, Tailwind CSS v4, `@code-ui/components`, and `@code-ui/plugin-vite`:

::code-group

```bash [pnpm]
pnpm dlx @code-ui/cli create my-miniapp
```

```bash [npm]
npx @code-ui/cli create my-miniapp
```

```bash [yarn]
yarn dlx @code-ui/cli create my-miniapp
```

::

The interactive prompt asks (in English) for:
- **Project folder name** & **WeChat MiniProgram AppID** (`touristappid` by default)
- **Primary brand color palette** (`red`, `emerald`, `blue`, `indigo`, `stone`, `violet`)
- **Default Iconify icon collection** (`lucide`, `tabler`, `heroicons`, `mdi`)
- **Component tag prefix** (`c` by default, e.g. `<c-button>`)

Once generated, start the development build and open **WeChat DevTools**:

```bash [Terminal]
cd my-miniapp
pnpm dev
```

Import the project root directory (which points `miniprogramRoot` to `dist/`) in WeChat DevTools.

## Add to an Existing `weapp-vite` Project

If you already have a `weapp-vite` project, you can initialize Code UI automatically with `@code-ui/cli init` or configure it manually in 4 steps.

### Automatic Initialization

Run `init --install` in your project root to install the dependencies and generate `cui.config.ts`, `weapp-vite.config.ts`, and `src/app.css`:

```bash [Terminal]
pnpm dlx @code-ui/cli init --install
```

### Manual Setup

#### 1. Install Dependencies

Since `weapp-vite` already comes with built-in Tailwind CSS (`weapp-tailwindcss`) and `@code-ui/plugin-vite` includes **Lucide** icons (`@iconify-json/lucide`) by default, you only need to install `@code-ui/components` and `@code-ui/plugin-vite`:

::code-group

```bash [pnpm]
pnpm add @code-ui/components @code-ui/plugin-vite
```

```bash [npm]
npm i @code-ui/components @code-ui/plugin-vite
```

```bash [yarn]
yarn add @code-ui/components @code-ui/plugin-vite
```

::

If you want to use an additional Iconify set (such as Tabler or Heroicons), install its `@iconify-json/<collection>` package as a dev dependency (for example `pnpm add -D @iconify-json/tabler`).

#### 2. Configure `weapp-vite.config.ts`

Register the `codeUI()` plugin and point `weapp.tailwindcss.cssEntries` to `src/app.css`:

```ts [weapp-vite.config.ts]
import { defineConfig } from "weapp-vite";
import { codeUI } from "@code-ui/plugin-vite";

export default defineConfig(({ mode }) => ({
  weapp: {
    srcRoot: "src",
    platform: "weapp",
    tailwindcss: {
      cssEntries: ["src/app.css"],
      cssOptions: {
        rem2rpx: true,
        autoprefixer: true,
      },
    },
  },
  plugins: [
    codeUI({
      autoImport: true,
      treeShake: mode === "production",
    }),
  ],
}));
```

#### 3. Import Styles in `src/app.css`

Create `src/app.css` and import Tailwind CSS v4 and `@code-ui/components`:

```css [src/app.css]
@import "tailwindcss";
@import "@code-ui/components";

* {
  box-sizing: border-box;
}
```

#### 4. Create `cui.config.ts`

Create a `cui.config.ts` file in your project root to configure your prefix, semantic colors, and icon collections:

```ts [cui.config.ts]
import { defineConfig } from "@code-ui/plugin-vite";

export default defineConfig({
  prefix: "c",
  ui: {
    colors: {
      primary: "red",
      secondary: "stone",
      neutral: "zinc",
    },
    colorMode: "system",
  },
  icons: {
    collections: ["lucide"],
  },
});
```

## Vite Plugin Options (`codeUI()`)

`@code-ui/plugin-vite` automates component registration, theme compilation, `<c-app>` wrapping, static slot detection, and production tree-shaking:

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `autoImport` | `boolean \| AutoImportOptions` | `false` | Scans `.wxml` templates for `<c-*>` tags and automatically injects `usingComponents` entries into each page or component's `.json` file. |
| `treeShake` | `boolean \| TreeShakeOptions` | `false` | Traces used components in `usingComponents` and prunes unused component folders (`runtime/*`), `.wxs` scripts, and shared JS chunks from `dist/miniprogram_npm/@code-ui/components`. Recommended for production (`mode === "production"`). |
| `appWrapper` | `boolean \| AppWrapperOptions` | `true` | Automatically wraps page WXML templates in `<c-app>` so global toast/dialog hosts and light/dark theme variables propagate to all child components and `<root-portal>` overlays. |
| `slotDetect` | `boolean \| SlotDetectOptions` | `true` | Statically analyzes WXML templates at build time and injects active slot flags (`_s`) into Code UI components so named slots and prop fallbacks switch automatically. |
| `icons` | `boolean \| IconsPluginOptions` | `"auto"` | Automatically injects `@plugin "@code-ui/plugin-vite/icons";` into your app stylesheet, providing built-in **Lucide** icons (`@iconify-json/lucide`) out of the box plus any extra `@iconify-json/*` packages installed in your project. |
| `configFile` | `string` | `"cui.config"` | Custom config file name to load via `c12`. |
